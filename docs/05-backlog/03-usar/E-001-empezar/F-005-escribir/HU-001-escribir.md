# HU-001 — Que la pregunta cambie el lienzo

Como persona que ya puede preguntar, quiero que una respuesta confirmada agregue o complete una tarjeta en este lienzo.

**Aceptación**

- WHEN el chat propone un cambio THEN no se escribe hasta que la persona lo confirme.
- WHEN confirma THEN el cambio pasa por el mismo guardado que el lienzo, y Simular flujo vuelve a leer el faltante.
- Un valor de secreto no se inventa ni se escribe en el chat.

**Tablero**

No aplica. No está implementado.
