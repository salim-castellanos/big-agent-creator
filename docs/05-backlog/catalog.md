## Orden de 03-usar

1. Inicializar con un ejemplo. Hecho en este corte.
2. Decir si Docker no está instalado o no está en marcha. Hecho en este corte.
3. Marcar la tarjeta incompleta, el campo en rojo y Simular flujo. Hecho en este corte.
4. Preguntar al modelo del editor sobre ese faltante, después de una prueba de comunicación. Hecho en este corte. El chat no escribe el lienzo.
5. Que esa pregunta pueda cambiar el lienzo. Siguiente. No está en este corte.
