# Hello

The first run. One Agent card. No Telegram.

1. Open this folder in VS Code or Cursor, then BigAgentCreator. Or, from any folder, **Examples → Hello**.
2. Secrets: set `CURSOR_API_KEY`.
3. Ship → Start.
4. Open http://127.0.0.1:3000/playground and type `hi`.

The reply is `hello`. The steps for editing, secrets, and Telegram are in [the start guide](../../docs/start.md).
